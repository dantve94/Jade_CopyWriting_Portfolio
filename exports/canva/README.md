# Canva files

PDF exports of every page of the portfolio site, in the sunflower theme, ready to import into Canva as editable designs.

- `Jade-Robertson-Portfolio-all-pages.pdf`: all 17 pages in one file (one Canva design with 17 pages)
- `01-home.pdf` … `17-work-9-goshawk-street.pdf`: one page each, if you only want to edit a single page

## Import into Canva

1. In Canva, go to **Create a design → Import file** (or drag the PDF onto the Canva home page).
2. Pick the PDF. Canva converts it into an editable design: text becomes editable text boxes and shapes become editable elements.
3. If Canva swaps a font, set it back to the theme fonts below (both are in Canva's font library).

Each page is one long canvas, 1280px wide, the same as the website on a desktop.

## Theme reference

| Use | Colour |
|---|---|
| Background (cream) | `#FFFDF7` |
| Sunflower yellow (buttons, highlights, rules) | `#F5B700` |
| Pale petal (highlighter) | `#FDE9A8` |
| Text (seed brown) | `#2B2118` |
| Secondary text | `#594A3B` |
| Dark gold (small labels) | `#8A5A00` |
| Divider lines | `#EFE6D3` |

| Use | Font |
|---|---|
| Headings and the copy itself | Source Serif 4 (Semibold for headings, Regular for body) |
| Navigation, labels, buttons | Inter (Regular / Medium) |
| Handwritten accents ("hi there!", sign-off, notes) | Caveat (Semibold) |

## Note

Changes made in Canva don't flow back to the website. The website is built from the Markdown files in `content/samples/`, so update those too, or ask for the site to be updated to match.
