#### Topic 1: What is Google Analytics 4?

##### What is GA4?

Google Analytics 4 (GA4) is the newest version of Google Analytics. This is a whole new generation of web analytics that will allow marketers to effectively analyse important customer usage metrics, not just track traffic. Google Analytics 4 tracks the entire customer path across multiple platforms and leverages AI and machine learning to provide more detailed insights into how users interact with your website and app.

GA4 is also focused on customer privacy. This comes as a result of some of the latest privacy laws, such as GDPR and CCPA. With privacy-first tracking, cross-channel data measurement, and AI-driven predictive analytics, GA4 is an advanced tool that provides unparalleled insights.

GA4 is now officially the recommended property type of Google Analytics (See topic 2). It used to be called App+Web Property when it was first added. Why App+Web? Well, the new property can track both App and Web visits in a single Google Analytics property instead of having those differing platform visits separated into different GA properties. Late in 2020, that App+Web Property was rebadged and re-released as Google Analytics 4 (GA4).

Note: A property in Google Analytics is a website, mobile app, or blog that is associated with a unique tracking ID. It is used to collect data about user interactions with the website, mobile app, or blog. This data is then analysed to gain insights into user behaviour.

Note: Universal Analytics (UA) properties will stop collecting new hits on 1 July 2023 for UA users and 1 October 2023 for GA360 users. Data will be available in a read-only format for a 6-month period after UA sunset.

Note: Important to note is there will be NO way to export your historical UA data into GA4, so starting your migration process as soon as possible is essential.

##### Is GA4 still free?

Google says, “Google Analytics has always offered a free version to help businesses of all sizes and stages to better analyse and improve their websites and apps. This mission hasn’t changed.”

GA4 will therefore also come with a free version – and this will come with some great features previously available only with a paid GA360 subscription

The most valuable feature is free BigQuery export. While standard GA users could already take advantage of the reporting or management APIs, this simply doesn’t stack up to the depth of data available in the BigQuery export, and also requires development effort.

Another major feature previously only available via a GA360 subscription is custom funnel analysis and reports. Not only are these now free but they’re also much more intuitive and easier to both create and view in GA4.

##### Why is UA updating to GA4?

According to Google

“GA4 isn’t so much an update, but an entirely new way of doing analytics – set up to scale for the future, work in a cookieless world, and be a lot more privacy-conscious.”

Note: Google Analytics uses a cookie, called the "_ga" cookie, to store a unique, anonymous identifier. This identifier is used to distinguish unique users and track their activity on a website. The cookie is typically stored on the user's device for up to two years.

GA4 has a new data model

UA uses a session-based data model and collects data as various hit types within these sessions (Which is why watching four videos in one session would only count as one conversion in UA). GA4 is user-based and designed to blend app and web data with an event-based data collection model.
